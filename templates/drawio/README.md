# Draw.io Templates

This directory contains Draw.io (diagrams.net) template files for architecture diagrams.

---

## Available Templates

| Template | Description | File |
|----------|-------------|------|
| Context Diagram | System context diagram showing external actors and systems | context-diagram.drawio |
| Container Diagram | High-level container view of the system | container-diagram.drawio |
| Component Diagram | Component-level design | component-diagram.drawio |
| Deployment Diagram | Infrastructure and deployment topology | deployment-diagram.drawio |
| Sequence Diagram | Interaction flow between components | sequence-diagram.drawio |
| ERD | Entity-relationship diagram | erd.drawio |

---

## Usage

1. Open the template in Draw.io (https://app.diagrams.net)
2. Modify the diagram for your project
3. Export as needed
4. Store the diagram in your project repository

---

## Best Practices

- Use consistent colors and shapes.
- Include a legend.
- Name all elements.
- Keep diagrams at the right abstraction level.
- Update diagrams when the architecture changes.
