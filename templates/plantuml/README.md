# PlantUML Templates

This directory contains PlantUML template files for architecture diagrams.

---

## Available Templates

| Template | Description | File |
|----------|-------------|------|
| Context Diagram | System context diagram | context-diagram.puml |
| Container Diagram | High-level container view | container-diagram.puml |
| Component Diagram | Component-level design | component-diagram.puml |
| Deployment Diagram | Infrastructure topology | deployment-diagram.puml |
| Sequence Diagram | Interaction flow | sequence-diagram.puml |
| ERD | Entity-relationship diagram | erd.puml |
| Activity Diagram | Business process flow | activity-diagram.puml |
| State Diagram | State machine | state-diagram.puml |

---

## Usage

1. Use a PlantUML-compatible editor or VS Code extension
2. Modify the template for your project
3. Generate the diagram (PNG, SVG, or PDF)
4. Store the source `.puml` file in your project repository

---

## Best Practices

- Use `!include` for reusable components.
- Use packages to group related elements.
- Keep diagrams focused on one concern.
- Update diagrams when the architecture changes.
- Use C4 model conventions where appropriate.
